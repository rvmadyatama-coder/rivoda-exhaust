RIVODA EXHAUST - PROFESSIONAL STORE

1. Salin semua file ke folder website RIVODA EXHAUST Anda.
2. Pastikan banner.png, 3.png, 4.png, dan 5.png berada di folder yang sama.
3. Buka index.html di Chrome.
4. Untuk mengganti harga, edit data-harga pada tag <body> di halaman produk dan harga tampilan di index.html.
5. Untuk mengganti nomor WhatsApp toko, cari 6287826441409 di script.js dan kontak.html.
6. Untuk mengganti alamat/email, edit kontak.html dan footer index.html.
7. Keranjang tersimpan di browser menggunakan localStorage.
8. Checkout mengirim detail pesanan ke WhatsApp toko.
